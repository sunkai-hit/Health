## 需求走查重点

1. **症状定位：** 是否必须引入 3D 人体？建议首版只采用 2D 正/背 SVG；以简洁为先。
2. **AI 风险级别：** “未识别明确紧急信号”不是“可以放心”的意思，不能使用“安全/无需就医”等强承诺文案。
3. **医疗安全：** 规则及测试用例由专业人员审核；未通过时只能内部概念验证，不对外分诊。
4. **用药：** 药名自动识别误差与剂量单位误差属于高危风险；V0.1 坚持人工确认。
5. **多端：** 先 PWA，再考虑原生 App；离线能力和账号登录要做取舍。
6. **临床报告：** 优先给医生事实性摘要，AI 推断单独放在可选附录。
