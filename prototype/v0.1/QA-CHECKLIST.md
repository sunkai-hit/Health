# Health V0.1 原型测试清单

## 检查说明

- 测试对象：\`prototype/v0.1/index.html\` + \`styles.css\` + \`app.js\`
- 使用虚构测试数据；**严禁输入或上传真实健康信息**
- 这是人工走查清单，不代表已执行的测试报告。
- 测试视口建议：375px、390px、768px、1280px。
- 不包含真实医学风险分级，也不能用于验证医疗规则的准确率。

## A. 基础交互

- [ ] 页面在本地直接打开，无外部资源依赖、无控制台报错。
- [ ] 桌面左侧导航及手机底部导航均能切换对应页面。
- [ ] 切页后标题、副标题、当前导航高亮同步。
- [ ] 375px 视口无严重横向滚动、底部按钮可点击。
- [ ] 刷新后恢复虚构示例，不保留输入数据；没有意外网络请求。

## B. 人体图

- [ ] 正面/背面可切换，区域能被点击、高亮和再次取消。
- [ ] 同一视图可选择多个区域，跨正反面选择会保留。
- [ ] 已选标签与 SVG 高亮一致，标签上的“×”删除有效。
- [ ] 人体左右以本人身体为准；选择左侧标签与图形对应。
- [ ] 开启“全身 / 位置不明”会清除具体部位；反向再点取消。
- [ ] 不选择具体位置也可以凭症状文字保存。
- [ ] SVG 区域可通过键盘 Tab 聚焦、Enter/空格切换（需真实浏览器测试）。

## C. 症状与事件

- [ ] 症状标签可多选与取消。
- [ ] 不适程度初始为“未评分”，滑块禁用；用户取消勾选后才记录具体分数。
- [ ] 保存至少需要部位/类型/描述之一，空表单应提示且不创建空事件。
- [ ] 新建事件名称可修改，用户取消命名时不应产生新事件。
- [ ] 新记录可挂接已有事件，保存后出现在对应时间线。
- [ ] 补记发生时间后，时间线按实际发生时间排序。
- [ ] 事件结束/重新开启状态显示一致。
- [ ] 多事件切换后报告和用药关联当前事件一致。

## D. 用药记录

- [ ] 未填药名或用量时不能保存。
- [ ] 有药名/剂量/单位/时间/事件时可添加用药记录。
- [ ] 用药后感受按用户原文显示，不被解释成明确因果。
- [ ] 药名/剂量的 HTML 特殊字符在界面中仅作为文本显示，无脚本执行风险。
- [ ] 用药记录出现在事件时间线、用药汇总和就医报告。

## E. AI 页面和安全提示

- [ ] 页面清楚说明“模拟问询、未启用真实医学分诊”。
- [ ] 3 道示例问询可依次选择答案，包括“不确定”。
- [ ] 结束后显示用户所选答案，不输出疾病概率、诊断或用药建议。
- [ ] 点击“紧急风险提示样式示例”仅展示通用模板，不引用当前事件作个人风险判断。
- [ ] 模板可以关闭，点击遮罩和 Escape 可以退出。

## F. 报告

- [ ] 选中事件后报告显示对应标题、日期和状态。
- [ ] 报告包含用户自述症状、身体部位（含标记示意图）、时间线、实际用药。
- [ ] 缺少症状/用药等信息时正常显示缺省状态，不编造。
- [ ] 默认不附 AI 内容；勾选附加后只显示原型说明。
- [ ] 复制按钮成功时有提示；权限失败时给出替代方式。
- [ ] 浏览器打印输出 A4 布局，无侧栏和表单控件，适合另存 PDF。

## G. 尚未具备的正式产品安全测试

- [ ] 用户身份鉴别、跨用户数据隔离、最小权限。
- [ ] 敏感健康信息的存储保护、传输加密、撤回授权、导出及删除。
- [ ] 第三方 AI 服务数据保留政策与授权验证。
- [ ] 医学审核的危险信号规则、无结果/未知/矛盾信息分支与临床验证集。
- [ ] 负面例子、边界例子、模型升级回归及误报漏报评估。
- [ ] 数据可追溯、修改审计、生成报告快照与临床内容区分。
